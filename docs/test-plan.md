# Phase 0 Test Plan (`splitpayng`)

## Environment & Prisma Migration Notes

- **Migrations vs. Schema (`prisma migrate diff`)**: Running `npx prisma migrate diff --from-migrations prisma/migrations --to-schema-datamodel prisma/schema.prisma` fails with `Error: Could not determine the connector from the migrations directory (missing migration_lock.toml)`. Furthermore, `master` only had `0_init`, whereas `phase-0-tests` and the current working tree added migrations `20261023091500_add_payout_attempts`, `20261023094500_add_payout_retry_window`, and `20261023172500_add_membership_billing_fields`. Therefore, the test `globalSetup.ts` syncs the test database schema using `npx prisma db push --skip-generate --accept-data-loss` (documented here for `TEST_REPORT.md` as well).
- **Test Database**: `docker-compose.test.yml` provisions `postgres:15-alpine` on port `5433` (`splitpayng_test`, `tmpfs`). In environments where Docker is unavailable, `globalSetup.ts` probes `127.0.0.1:5433` first and falls back to creating/using an isolated `splitpayng_test` database on local PostgreSQL (`localhost:5432`).
